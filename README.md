# IP1 Project

## How to Run

### Prerequisites
- Node.js >= 18
- npm >= 9

### Frontend (Vue 3 + Vite + TypeScript)
```bash
cd web
npm install
npm run dev
```
App runs at `http://localhost:5173`

### Backend (NestJS + Prisma)
```bash
cd api
npm install
npx prisma generate
npm run start:dev
```
API runs at `http://localhost:3000`
